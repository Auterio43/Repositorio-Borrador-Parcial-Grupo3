**Descripción del escenario:**
Simulación de una red social tipo Instagram.
El sistema representa usuarios (normales y VIP/verificados) que pueden seguirse entre sí, crear publicaciones y reaccionar a las publicaciones de otros mediante likes, comentarios y compartidos. Cada usuario guarda su propia lista de seguidores, seguidos y publicaciones. Los usuarios VIP, además, acumulan ganancias en función de las interacciones que reciben. El objetivo es aplicar los conceptos básicos de POO: clases, objetos, atributos, métodos, encapsulamiento, herencia y relaciones simples.
